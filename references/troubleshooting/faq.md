# 账户要求与常见问题

来自 IPAbuyer 的用户实践，面向最终用户；运行层面的报错见 [errors.md](errors.md)。

- **无法获取双重验证码**：仅以手机号作为验证手段的账户收不到验证码。请让用户到 <https://account.apple.com/> 获取。
- **账户密码正确却无法登录**：苹果的账户政策要求账户登录过 iCloud 与 App Store，并在 App Store 完成过一次有效购买（免费应用即可），否则第三方客户端无法登录。
- **购买后 iPhone 仍显示未购买**：iPhone 不会立即刷新已购列表，在 iPhone 上对任意 App 完成一次购买（含免费 App）即可刷新。
- **为什么默认只自动购买免费 App**：购买付费 App 会真实产生扣费。为账户安全起见，本技能对付费 App 一律先向用户确认。
- **为什么推荐用户自己运行登录命令**：一是保护密码——交互式登录中 Apple ID 密码只在用户终端隐藏输入，不经过 AI 助手；二是稳定——ipatool 无法主动请求 Apple 下发验证码，非交互代跑依赖验证码推送，桌面版 IPAbuyer 曾用假验证码 000000 触发下发，路径不稳定。
- **下载的应用如何更新**：IPA 与下载时使用的 Apple ID 绑定。安装到设备后，需要在该设备的 App Store 登录同一个 Apple ID 才能进行应用更新；换 ID 登录则无法更新该应用。
