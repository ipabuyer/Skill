# App Store 直达链接

向用户展示候选或报告结果时，可附上应用商店页面直达链接。链接由区域码与 trackId 构成，以下规则均已实测验证。

## 链接格式

```text
https://apps.apple.com/<区域码>/app/id<trackId>
```

示例（中国大陆区）：`https://apps.apple.com/cn/app/id1242689729`

- 区域码即账户的 App Store 区域（ipatool 搜索跟随的 storefront），如 `cn`、`us`。
- `id` 形式无需拼接应用名 slug，服务端会自动 301 到带名称的规范 URL。
- **始终显式写区域码**：省略时按访问者 IP 所在地区跳转，结果不可控。

## 区域限制（重要）

链接只对「该区域已上架」的应用有效，跨区域访问会被服务端拦截。实测行为：

- 应用未在链接区域上架、访问者位于中国大陆：外区页面（如 `/us/…`）被 **302 跳转到大陆区首页**，用户根本看不到应用页面。
- 用未上架区域的路径访问（如外区应用套 `/cn/…`）：**404**。

因此：

1. 给链接前先确认应用在用户账户区域上架。ipatool 搜索得到的结果天然满足（跟随账户 storefront）；从 iTunes Search API 其他区域数据取来的应用**不满足**。
2. 推荐外区应用时要明确告知「该应用不在你的账户区域上架，链接无法在本地打开，且当前账户无法购买下载」，不要给一个点了就跳首页的链接。
